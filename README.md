## Summary

This repository is a simple Spring MVC web application with controllers, entities, repositories, and services.

## Structure

- `src/main/java/org/example/springmvcproject` - application source
  - `controller/` - MVC controllers
  - `entity/` - JPA entities
  - `repository/` - data repositories
  - `services/` - business logic
  - `scopes/` - custom scope classes

- `src/main/resources/templates` - Thymeleaf templates

## Requirements

- Java 17+ (or the JDK version used in `pom.xml`)
- Maven (the project includes the Maven wrapper)

## Useful Targets

- Open the application in a browser at `http://localhost:8080` after running.
- Templates available in `src/main/resources/templates`.
